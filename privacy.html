Privacy policy / Zásady ochrany soukromí

Last updated: 2026-09-01

English

drfood is a personal application operated and used by a single individual (the owner). It is not distributed to or usable by anyone else.

Data accessed. With the owner's explicit consent, drfood reads the owner's own health and fitness data from the Google Health API (activity and fitness, sleep, health metrics and measurements) using read-only scopes.

Use. The data is used solely to generate private daily and weekly summaries for the owner. It is not used for advertising, profiling, or any other purpose.

Storage. Data is processed and stored only on the owner's own computer. It is never uploaded to any third-party service and never shared, sold, or transferred to anyone.

Google API Services User Data Policy. drfood's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation. Access can be revoked at any time at myaccount.google.com/permissions; locally stored data can be deleted by the owner at any time.

Česky

drfood je osobní aplikace provozovaná a používaná jediným člověkem (vlastníkem). Nikomu dalšímu není poskytována.

Se souhlasem vlastníka čte pouze jeho vlastní zdravotní a fitness data z Google Health API (aktivita, spánek, zdravotní metriky) v režimu jen pro čtení. Data slouží výhradně k tvorbě soukromých denních a týdenních přehledů, jsou zpracovávána a ukládána jen na počítači vlastníka a nikdy nejsou předávána třetím stranám. Použití dat z Google API se řídí zásadami Google API Services User Data Policy včetně požadavků Limited Use. Přístup lze kdykoli odvolat na myaccount.google.com/permissions.
